# Card Compass · 刷哪张

为 iPhone 设计的信用卡消费前助手。可安装到主屏幕，按消费类别、积分估值、已激活商户优惠和境外交易费比较五张卡。

支持 Chase Sapphire Preferred、Freedom Unlimited、Bilt Obsidian、Capital One VentureOne 和 Savor。公开政策核验日期：2026-10-06。详细条款与官方来源见 [权益说明](docs/card-policies.md)。

## 在手机上使用

用 Safari 打开部署后的网址，选择「分享 → 添加到主屏幕」。付款前打开「刷哪张」，输入金额、消费类别和商家。先在「设置」确认积分估值、Bilt 的奖励模式和所选加倍类别。

「优惠」可记录银行账户中看到的专属优惠，包含激活、最低消费、返还上限、有效期及使用状态。未激活或过期优惠不参与推荐；多项优惠未确认可叠加时仅计算价值最高的一项。到期日可导出日历事件，附带提前一天的提醒，实际提醒取决于日历权限和设置。

快捷指令可用「打开 URL」打开 `https://<账号>.github.io/<仓库>/?category=dining&amount=50&merchant=Example`，放在锁屏、主屏幕或操作按钮。快捷方式参数仅预填，付款仍在商家的正常流程完成。

## 数据和更新

个人设置及优惠仅存储于当前浏览器，不上传到 GitHub。不要录入卡号、验证码或银行密码。不同手机和浏览器不会自动同步；使用 JSON 备份导出/导入迁移，备份包含个人优惠，请自行保管。

银行的登录后专属优惠需要本人录入及激活。这里没有银行账户连接，也不能检测即将发生的 Apple Pay 付款。公开网页每周由 GitHub Actions 检测变动；网页变动状态不等于条款已经复核。卡片规则需核对官方条款后更新 `public/data/catalog.json`；界面刷新获取最新发布数据。没有可供公开网页可靠自动获取的所有个人实时优惠。

推荐计算的是本次已知的可量化回馈，不保证绝对最大收益。积分价值由用户设定；保险、住房积分门槛、开卡奖励、账户专属转点加成、平台价差等需另行比较。年费视为已经持卡的既定成本。酒店抵扣不自动加进排序，避免不清楚剩余额度时重复计入；被抵扣部分不赚积分的条款须单独核对。以银行实际商户分类及账户条款为准。

## 本地开发

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

静态渐进式网页应用（Progressive Web App, PWA），无运行时服务端、追踪器或银行凭证。源码采用 JavaScript，计算逻辑位于 `src/engine.js`。GitHub Pages 部署及每周来源监测位于 `.github/workflows/`。仓库设置中选择 Pages → GitHub Actions，然后运行部署工作流。

`tmp/` 保存本地研究和检查材料，不进入仓库。
